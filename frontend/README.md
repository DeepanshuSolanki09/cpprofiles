This is the frontend component of the **CP Profiles** application built with [Next.js](https://nextjs.org).

> [!TIP]
> For the complete system architecture, comprehensive Mermaid diagrams, and full-stack setup instructions, please see the primary root [`README.md`](../README.md).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
